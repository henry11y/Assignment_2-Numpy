# Assignment_2-Numpy

This project analyzes basketball statistics usding Python and NumPy.


Files

- 'Assignment 2 Numpy.py' - Python scripti used to lead, clean, and analyze the data
- 'player_season_results.csv' - Output file containing per-player, per-season statistics

 Methods

- Data loaded from a CSV file
- Calculations performed using NumPy arrays
- Safe division used to handle divide-be-zero caes
- Statistics grouped by player and season


 Output

  The script calculates:
- Field goal accuracy
- Three-point accuracy
- Free throw accuracy
- Points per minute
- Overall shooting accuracy
